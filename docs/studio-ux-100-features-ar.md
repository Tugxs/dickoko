## قاعدة التجربة

المستخدم لا ينتقل مباشرة إلى تنفيذ غامض. يختار السيرفر، يراجع حالته، يختار وظيفة Bot، يحدد الأوامر، يشاهد المعاينة، يحفظ المسودة، ثم ينشئ خطة تغيير قابلة للمراجعة. المعاينة لا تعدّل Discord، وملف Bot لا يحتوي Token، ولا يتم تنفيذ العمليات الحساسة دون موافقة واضحة.
