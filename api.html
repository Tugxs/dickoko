01

الحالة الحالية

الواجهة البرمجية العامة ليست متاحة للاستخدام العام بعد. لا تنشئ مفاتيح أو تعتمد على مسارات داخلية غير موثقة.

02

ما نخطط له

نهدف إلى توفير مفاتيح محدودة النطاق، توثيق للإصدارات، حدود استخدام، وسجل أخطاء مفهوم.

03

للشركات

إذا كان لديك تكامل ضروري الآن، اشرح الحالة في صفحة المبيعات والشركات. سنفصل الحل المؤقت عن API العام عند توفره.

04

إشعار الإطلاق

سنعرض في سجل التحديثات ما تغير، ونوضح سياسة التوافق والحدود قبل فتح الوصول.
